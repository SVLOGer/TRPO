**Дата:** 26 ноября 2025 г.
**Статус:** Принято

**Контекст:**

Для создания клиентских приложений (веб-интерфейс и мобильные приложения) нам необходимо выбрать соответствующие технологии, обеспечивающие хороший пользовательский опыт, производительность и кроссплатформенную совместимость.

**Рассмотренные варианты:**

1. **React + React Native:** Единая технология для веба и мобильных приложений
2. **Flutter:** Кроссплатформенный фреймворк от Google
3. **Нативная разработка:** Separate iOS (Swift) и Android (Kotlin) приложения
4. **Vue.js + Capacitor:** Альтернативный веб-стек для кроссплатформенных приложений

**Решение:**

Выбрана связка React для веб-приложения и React Native для мобильных приложений.

**Обоснование:**

- **Единая кодовая база:** Общая логика и компоненты между вебом и мобильными приложениями
- **Большое сообщество:** Огромная экосистема библиотек и инструментов
- **TypeScript поддержка:** Статическая типизация для повышения надежности
- **Производительность:** Достаточная производительность для большинства сценариев
- **Гибкость:** Возможность использовать нативные модули при необходимости
- **Рынок труда:** Большое количество доступных разработчиков

**Последствия:**

- Веб-приложение будет разработано на React + TypeScript
- Мобильные приложения для iOS и Android на React Native
- Общие библиотеки компонентов для сохранения консистентности UI/UX
- Необходимость настройки монорепозитория для общего кода
