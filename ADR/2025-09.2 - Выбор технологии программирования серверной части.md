**Дата:** 26 ноября 2025 г.
**Статус:** Принято

**Контекст:**

При разработке серверной части нашей платформы для аренды транспортных средств нам необходимо выбрать технологию программирования. Этот выбор влияет на производительность, масштабируемость, безопасность и возможность привлечения разработчиков.

**Рассмотренные варианты:**

1. **Java:** Надежный язык с богатой экосистемой и проверенной производительностью
2. **Kotlin:** Современный язык для JVM с выразительным синтаксисом и полной совместимостью с Java
3. **Go:** Простой и эффективный язык с отличной поддержкой параллелизма
4. **Python:** Язык с быстрой разработкой, но потенциальными проблемами производительности
5. **Node.js:** JavaScript на сервере, хорош для I/O-нагрузок

**Решение:**

Выбран Kotlin.

**Обоснование:**

- **Совместимость с Java:** Полная интеграция с Java-экосистемой и библиотеками
- **Безопасность типов:** Null-safety предотвращает распространенные ошибки
- **Корутины:** Эффективная поддержка асинхронного программирования
- **Выразительность:** Современный синтаксис уменьшает объем boilerplate-кода
- **Производительность:** Сопоставима с Java, подходит для высоконагруженных систем
- **Поддержка Spring:** Отличная интеграция с Spring Boot для быстрой разработки микросервисов

**Последствия:**

- Все серверные микросервисы будут разработаны на Kotlin
- Использование Spring Boot и Spring Cloud для микросервисной архитектуры
- Необходимо обеспечить обучение команды best practices Kotlin
- Использование корутин для асинхронной обработки запросов
